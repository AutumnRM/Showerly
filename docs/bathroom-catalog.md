## 说明
- `sex`：0=男、1=女、2=混合/其他（外包系统里的分类，可能含非浴室）。
- 疑似非浴室：如“洗车房”“游泳馆浴室”“测试”等，后续 App 可按名称/类型过滤。
- `useCount` 可小于 0：说明统计有抖动，处理时一律 `max(0, useCount)`。
- 与 `campusId` 的关系：`?campusId=4` 只返回该校区（5 条）；不带参数返回全校 134 条。校区 ID 需按需枚举并记录。
