# iOS 快捷指令（Shortcuts）搭建指南

> 目标：在 iPhone 上用“快捷指令 App”点按即可查澡堂人流。请求地址同安卓端一致，先直连校方接口，后期切到 Workers。

## 前置配置
- 在 `设置 > 快捷指令 > 高级` 允许“共享安全性和不受信任的快捷指令”。
- 需要请求头鉴权时可自行填 token；若不想在快捷指令里存 token，则等 Phase 1 切到 Workers（token 放服务端）后再用。

## 搭建步骤
1. 打开“快捷指令”，新建快捷指令。
2. 添加“URL”动作，填入校方接口地址（或后期 Workers 的 `https://<your-worker>/api/current`）。
3. 添加“获取 URL 内容”动作，方法设为 `GET`；若有鉴权，展开“请求头”：键填 `Authorization`（或抓包得到的头名），值填 `Bearer <token>`。
4. 添加“从输入获取 JSON”动作，选择“获取 URL 内容”的输出。
5. 添加“从 JSON 获取值”：
   - 优先 `data.total`，若为空再取 `data.count` / `total`；`capacity` 取 `data.capacity` / `capacity`。
   - 抓包后按实际字段名调整。
6. 添加“计算”动作算占用率（若容量 > 0）：`total / capacity * 100`。
7. 添加“显示通知”或“显示结果”，把 `total`、`capacity`、占用率、更新时间拼成一段话。
8. 为了自动刷新，可再加“等待”+ 循环，或配合“自动化”定时触发。

## 示例展示文案
`当前 62 人 / 80 位 · 较拥挤 · 更新于 12:30`

## 限制
- 快捷指令无法使用大陆厂商推送通道；后期跨用户推送在 iOS 端只能回退为打开快捷指令/应用内查询。
- 若接口需要复杂签名或双向认证，快捷指令可能无法直接对接，需走 Workers 中转。
